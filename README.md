# AI Evals courses

Learner materials for the courses at [aievals.co/courses](https://www.aievals.co/courses): runnable labs, synthetic data, exercises with worked solutions, and templates for the written work. One folder per course.

| Folder | Course | What is inside |
|---|---|---|
| [voice-ai/](voice-ai/) | [Voice AI Evaluation](https://www.aievals.co/courses/voice-ai-advanced) | 12 labs, two editions of synthetic call data, 15 exercises with solutions, templates, tests |

Every course folder runs on its own: it has its own requirements, tests and README. The labs are the same standalone scripts the course site shows, and the tests check that each one reproduces its published output.
